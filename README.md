# Advanced Web Technology (Section F) - Fall 2026

Welcome to the official repository for the **Advanced Web Technology** course (Section F) for the **Fall 2026** semester. This repository contains all class projects, lab exercises, assignments, and course materials.

## 🚀 Course Overview
This course covers advanced concepts in modern web development, focusing on scalable architecture, advanced frameworks, API design, and deployment strategies.

## 🛠️ Tech Stack & Tools
* **Frontend:** Next.js
* **Backend:** Nest.js
* **Database:** PostgreSQL
* **Version Control:** Git & GitHub

## 📝 Getting Started
To run the projects locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project directory:**
   ```bash
   cd YOUR_REPO_NAME
   ```
3. **Install dependencies and node, typescript, nest, browser/postman:**
   ```bash
   npm install
   ```
